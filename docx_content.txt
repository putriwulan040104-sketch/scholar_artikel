Pengujian Precision at K

Setelah sistem menghasilkan pemeringkatan artikel menggunakan Cosine Similarity, tahap berikutnya adalah melakukan evaluasi untuk mengetahui ketepatan hasil pencarian yang ditampilkan pada posisi teratas. Evaluasi ini menggunakan metrik Precision at K karena fokus penelitian tidak hanya menghasilkan nilai kemiripan, tetapi juga menilai apakah artikel yang berada pada urutan teratas benar-benar relevan terhadap query pengguna.

Pada tahap awal, nilai threshold Cosine Similarity > 0,3 digunakan sebagai indikator awal relevansi. Dokumen dengan nilai similarity di atas 0,3 diberi tanda awal sebagai dokumen yang berpotensi relevan, sedangkan dokumen dengan nilai similarity di bawah atau sama dengan 0,3 diberi tanda awal sebagai dokumen yang memiliki tingkat kemiripan lebih rendah. Threshold tersebut tidak digunakan sebagai keputusan akhir dalam evaluasi Precision at K. Keputusan akhir relevansi tetap ditentukan berdasarkan Label Final dari tiga evaluator melalui human judgement.

Pada penelitian ini, nilai K yang digunakan adalah K=5, K=10, dan K=20. Ketiga nilai tersebut dipilih untuk melihat ketepatan sistem pada jumlah hasil pencarian yang paling mungkin diperhatikan oleh pengguna.

Persiapan Query Uji dan Ground Truth

Pengujian menggunakan 12 query uji yang disusun secara bilingual (Bahasa Indonesia dan Bahasa Inggris) dengan proporsi tiga query untuk setiap kategori artikel dalam korpus, yaitu Machine Learning, Web Application, Cyber Security, dan Mobile Application. Penyusunan query secara bilingual dilakukan karena korpus artikel yang digunakan terdiri dari campuran artikel berbahasa Indonesia dan Inggris, sehingga kemampuan sistem dalam menangani query dari kedua bahasa perlu diuji.

Setiap query dijalankan melalui fungsi pencarian sistem dengan top_k = 20 agar seluruh kebutuhan K (5, 10, dan 20) dapat dipenuhi dari satu kali proses pencarian. Hasil pencarian untuk seluruh 12 query kemudian dikumpulkan dan diserahkan kepada tiga evaluator independen untuk dinilai relevansinya terhadap masing-masing query, tanpa evaluator mengetahui skor kemiripan yang dihasilkan sistem. Setiap evaluator memberikan label biner (1 = relevan, 0 = tidak relevan) pada setiap pasangan artikel-query. Label Final ditentukan melalui majority vote (konsensus minimal 2 dari 3 evaluator). Berkas ground truth inilah yang digunakan sebagai acuan pada perhitungan Precision@K.

Dari total 225 pasangan artikel-query yang dinilai, sebanyak 196 artikel (87,1%) dinyatakan relevan dan 29 artikel (12,9%) dinyatakan tidak relevan berdasarkan konsensus evaluator.

Implementasi Pencarian dan Perhitungan Precision@K

Proses pencarian pada tahap evaluasi menggunakan pipeline yang sama dengan sistem pencarian utama. Query terlebih dahulu melalui tahap preprocessing yang terdiri dari cleaning (lowercase, hapus URL, hapus non-alfanumerik), tokenisasi, penghapusan stopword, dan stemming menggunakan Sastrawi. Urutan tahapan ini identik dengan preprocessing dokumen pada tahap pembangunan model TF-IDF.

Kode Program 4.x Fungsi preprocess_query

def preprocess_query(query):

    cleaned = clean_text(query)

    tokens = cleaned.split()

    tokens = [t for t in tokens if t not in stop_words and len(t) > 1]

    tokens = [stemmer.stem(t) for t in tokens]

    return tokens

Berdasarkan Kode Program 4.x, fungsi preprocess_query mengubah query menjadi kumpulan token dasar melalui tahap pembersihan, penyaringan stopword, dan stemming, sebelum ditimbang menjadi vektor TF-IDF.

def build_query_vector(query_tokens):

    term_to_index = {term: i for i, term in enumerate(terms)}

    qv = np.zeros(len(terms), dtype=float)

    if not query_tokens:

        return qv.reshape(1, -1)

    total = len(query_tokens)

    counts = Counter(query_tokens)

    for term, count in counts.items():

        if term in term_to_index:

            tf = count / total

            idf = float(idf_scores.get(term, 0))

            qv[term_to_index[term]] = tf * idf

    return qv.reshape(1, -1)

Pada Kode Program 4.x, bobot setiap term pada vektor query dihitung dengan mengalikan term frequency (TF) query terhadap nilai inverse document frequency (IDF) yang telah dihasilkan pada tahap pembangunan model TF-IDF korpus, sehingga skema pembobotan antara query dan dokumen tetap konsisten.

Kode Program 4.x Fungsi search

def search(query, top_k=20, min_occurrence=0, threshold=0.3):

    query_tokens = preprocess_query(query)

    if not query_tokens:

        return pd.DataFrame()

    qv = build_query_vector(query_tokens)

    scores = cosine_similarity(qv, tfidf_matrix).flatten()

    results = doc_index.copy()

    results["similarity_score"] = scores

    results["occurrence"] = results["document_text"].apply(

        lambda t: count_occurrence(t, query_tokens))

    results = results[results["similarity_score"] > 0].copy()

    if min_occurrence > 0:

        results = results[results["occurrence"] >= min_occurrence].copy()

    results = results.sort_values("similarity_score", ascending=False)

    results = results.head(top_k).reset_index(drop=True)

    results["rank"] = range(1, len(results) + 1)

    results["threshold_relevan"] = (results["similarity_score"] > threshold).astype(int)

    results["interpretation"] = results["similarity_score"].apply(

        lambda s: interpret_similarity(s, threshold))

    return results

Berdasarkan Kode Program 4.x, fungsi search() digunakan untuk menjalankan proses pencarian artikel berdasarkan query evaluasi. Query terlebih dahulu melalui tahap preprocessing agar bentuk katanya sesuai dengan data dokumen yang telah diproses sebelumnya. Selanjutnya, query diubah menjadi vektor dan dibandingkan dengan matriks TF-IDF dokumen menggunakan cosine similarity untuk memperoleh nilai similarity_score. Hasil pencarian kemudian difilter agar hanya artikel dengan skor similarity lebih dari 0 yang digunakan, lalu diurutkan dari skor tertinggi ke terendah dan dibatasi sesuai nilai top_k.

Setelah hasil pencarian diperoleh, label relevansi dari ground truth digabungkan berdasarkan pasangan query dan article_id. Artikel yang memiliki Label Final = 1 diberi nilai relevan = 1, sedangkan artikel dengan Label Final = 0 atau tidak ditemukan pada ground truth diberi nilai relevan = 0. Precision@K kemudian dihitung untuk setiap query pada nilai K = 5, 10, dan 20.

Pengujian Perbandingan Metode Relasi Citation Graph

Selain evaluasi ketepatan pencarian menggunakan Precision@K, perlu dilakukan pengujian terhadap metode citation graph yang diusulkan. Pengujian ini bertujuan untuk membandingkan struktur jaringan relasi yang dihasilkan oleh tiga metode relasi yang diimplementasikan pada sistem, yaitu bibliographic coupling, keyword co-occurrence, dan co-authorship. Perbandingan dilakukan terhadap kumpulan artikel yang sama sehingga perbedaan struktur graf yang tampil murni disebabkan oleh perbedaan karakteristik metode relasi, bukan oleh perbedaan data yang digunakan.

Prosedur Pengujian

Pengujian perbandingan metode relasi dilakukan melalui beberapa tahap. Tahap pertama, seluruh artikel pada korpus dimuat dari basis data beserta metadata yang dibutuhkan masing-masing metode, yaitu daftar referensi untuk bibliographic coupling, kata kunci untuk keyword co-occurrence, dan penulis untuk co-authorship. Tahap kedua, setiap metode membangun indeks elemen pembentuk relasi kemudian mencocokkan pasangan artikel yang saling berbagi elemen yang sama untuk menghasilkan edge pada graf. Tahap ketiga, struktur graf dari ketiga metode dianalisis menggunakan pendekatan Social Network Analysis (SNA) untuk memperoleh metrik jaringan. Tahap keempat, metrik dari ketiga metode dibandingkan untuk mengetahui perbedaan dan keunggulan masing-masing.

Kode Program 4.x membangun graf menggunakan fungsi build pada masing-masing layanan relasi. Fungsi tersebut mengembalikan ringkasan hasil pembangunan graf berupa jumlah artikel yang diproses, jumlah relasi yang berhasil dicocokkan, serta jumlah edge yang ditambahkan, diperbarui, atau dilewati.

Perhitungan Metrik Jaringan

Setelah graf terbentuk, struktur jaringan dianalisis menggunakan metrik Social Network Analysis (SNA). Metrik yang dihitung meliputi jumlah node, jumlah edge, densitas graf, jumlah komponen terhubung, ukuran komponen terbesar, jumlah node terisolasi, rata-rata derajat, degree centrality, dan betweenness centrality. Metrik-metrik tersebut digunakan untuk menggambarkan karakteristik jaringan yang dihasilkan oleh setiap metode relasi.

Kode Program 4.x Perhitungan Metrik SNA

def build_sna_metrics(top_n=10, relation_type="bibliographic_coupling"):
    publications = _load_publications()
    relations = _load_relations(relation_type)
    node_ids, edges, adjacency = _build_graph(publications, relations)
    graph = nx.Graph()
    graph.add_nodes_from(node_ids)
    graph.add_edges_from((source, target) for source, target, _weight in edges)
    betweenness = nx.betweenness_centrality(graph)
    degree_centrality_map = nx.degree_centrality(graph)

Berdasarkan Kode Program 4.x, node pada graf merepresentasikan artikel, sedangkan edge merepresentasikan relasi antar artikel sesuai metode yang digunakan. Degree centrality menunjukkan banyaknya artikel lain yang terhubung langsung dengan suatu artikel, sedangkan betweenness centrality menunjukkan seberapa besar peran suatu artikel sebagai penghubung antar kelompok dalam jaringan. Metrik jaringan dihitung menggunakan library NetworkX pada Python.
